# User Stories

1. As a guest, I want to search hotels by city so that I can see where I can stay.
2. As a guest, I want to search by check-in and check-out dates so that I only see available rooms.
3. As a guest, I want to sort results by price or rating so that I can compare options.
4. As a guest, I want to book a room for my dates so that it is reserved for me.
5. As a guest, I want to see the total price based on the number of nights so that I know the cost.
6. As a guest, I want a discount for long stays so that I save money.
7. As a guest, I want to cancel my booking so that the room becomes available again.
8. As staff, I want to add hotels and rooms so that guests can book them.
9. As staff, I want to see all bookings so that I can manage the hotel.
10. As a user, I want my data saved when I close the app so that it is still there next time.
11. As a user, I want clear error messages (invalid dates, room taken) so that I know what went wrong.
